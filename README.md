# Nourish

Nourish is a free, 100% no-paywall SwiftUI iOS 17+ calorie-tracking app. It helps you track your nutrition with minimal aesthetics and earth-toned inspired design.

## Features

- **Metabolic Onboarding:** Calculates BMR/TDEE based on your stats.
- **Unified Scanner:** Scan barcodes, labels (OCR), or plate contents (AI classification) to log food.
- **Offline First:** SwiftData for persistence.
- **HealthKit Sync:** Bidirectional sync for steps, burned energy, and nutrition data.
- **Minimalist Design:** Soothing dark theme with earth-toned palette.

## Installation

- **IPA:** Install the `Nourish.ipa` via TrollStore on your device.
- **Source:** Open `Nourish.xcodeproj` in Xcode 15+ to build and run locally.

## Development

Project uses `xcodegen` and `SwiftPM`.

- `project.yml`: Define your project structure.
- `Package.swift`: Swift Package Manager manifest.
